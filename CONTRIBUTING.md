# Contributing

**SnapPost Forever does not accept external code contributions.**

This project is maintained solely by [Terynas](https://github.com/Terynas). Pull requests, patches, and unsolicited code drops will be closed without merge.

## What you can do

- **Use** the addon from authorized channels (e.g. CurseForge) under the terms in [`LICENSE`](LICENSE).
- **Report bugs** via GitHub Issues if the issue tracker is open — include client (Forever / Midnight), interface version (`/dump select(4, GetBuildInfo())`), steps to reproduce, and any BugSack error.
- **Ask questions** on the Terynas YouTube / community channels when linked from the project page.
- **Learn** how addons work in [First Timers](https://github.com/Terynas/First-Timers).

## What you must not do

- Open PRs expecting a merge
- Redistribute or republish modified copies (see `LICENSE` — All Rights Reserved)
- Submit secrets, API tokens, or account credentials in issues

## Maintainers

Follow [`AGENTS.md`](AGENTS.md) when editing this repo with coding tools.

- **Never push** to GitHub. Finish locally; the human runs push.
- Never add `Co-authored-by` / `Generated-by` (or similar) trailers.
- Commit only as **Terynas**. Local hooks under `.githooks/` enforce author and message policy.
