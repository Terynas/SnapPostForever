# Security

## Supported versions

Only the latest released version of SnapPost Forever is supported.

## Reporting

If you find a security issue in this addon (for example unsafe mail automation or SavedVariables handling), open a **private** report to the author via CurseForge messaging or GitHub Security Advisories if enabled — do not file a public issue with exploit detail.

## Policy

- Mail sends are player-driven from the mailbox UI with configurable delays
- No credential collection
- See `AGENTS.md` / First Timers security notes for development expectations
