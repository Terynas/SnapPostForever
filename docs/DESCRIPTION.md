**SnapPost Forever** maps profession materials across your characters and helps you mail the right stacks from the mailbox with safe delays — on **WoW Forever** and **Midnight / Mainline**.

## Features

- **Character scan** — save each alt’s professions (`/spostf scan`)
- **Mapper UI** — alt sidebar, profession chips, search, shared mats, per-item maps
- **Mailbox prompt** — icons, skip stacks, delayed bulk send
- **DE greens** — optional low-value Uncommon gear to your enchanter
- **First-time guide** + Options + minimap button
- Dual-ship: Forever (`Interface 16001`) + Midnight (`120105` / `120107`)

## Quick start

1. Log each crafting alt and run `/spostf scan`.
2. Open `/spostf`, pick an alt, assign professions or materials.
3. Gather, open a mailbox, use the SnapPost mail prompt.

## Commands

- `/spostf` — mapper  
- `/spostf options` — settings  
- `/spostf bags` — mail plan  
- `/spostf delay N` — seconds between sends  
- `/spostf de <Char-Realm>` — DE greens target  

## Notes

- Pairs well with **ProfessionMaster** for craft toasts and alt profession browsing.
- Forever uses full character names (first + surname) for keys and mail **To**.
